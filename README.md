# Stonehearth Russian Translation
Неофициальный перевод игры [Stonehearth](https://store.steampowered.com/app/253250/Stonehearth/) и модов Steam на Русский язык.

Список и статус перевода модов можно посмотреть в [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3466283052&searchtext=).

# Установка
1. Скачать как ZIP архив
2. Открыть папку **mods** в директории игры **\Stonehearth**
3. Скопировать папку **stonehearth-rus-translation-main** из архива в папку **\Stonehearth\mods** и переименовать её в **ru_lang**

*ВНИМАНИЕ*  
При *распаковке* архива папка может иметь вид  ↓  
**stonehearth-rus-translation-main\stonehearth-rus-translation-main\файлы_мода**           
Вам нужна *внутрянняя* папка, скопируйте её в **\Stonehearth\mods** и переименуйте в **ru_lang**

4. Финальный вид должен быть таким **\Stonehearth\mods\ru_lang**
5. В игре активировать в списке **Local Mods** - мод Russian Language и поменять язык в настройках игры
